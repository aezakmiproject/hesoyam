# Code of Conduct

Hesoyam welcomes contributors with different backgrounds and levels of experience. Be respectful in issues, pull requests, reviews, and other project discussions.

## Expected behavior

- Discuss ideas and code without personal attacks.
- Give specific, constructive feedback and assume good intent.
- Respect other people’s time, privacy, and boundaries.
- Help keep discussions relevant to the project.

Harassment, discrimination, threats, and publishing someone else’s private information are not acceptable. Maintainers may edit or remove harmful content, close discussions, or restrict participation when needed.

If a discussion becomes unsafe, use GitHub’s reporting tools or contact a repository maintainer privately. Do not post personal details in a public issue.
